# Conversor de Temperatura

Ferramenta web interativa desenvolvida para calcular e exibir automaticamente a equivalência de valores térmicos entre as três principais escalas termométricas: Celsius, Fahrenheit e Kelvin.

---

### Funcionalidades
- Conversão rápida a partir de qualquer uma das três escalas selecionadas
- Atualização dinâmica dos resultados na interface
- Validação básica de entrada numérica

---

### Tecnologias Utilizadas
- **Estruturação:** HTML5
- **Estilização:** CSS3
- **Lógica e Manipulação do DOM:** JavaScript
